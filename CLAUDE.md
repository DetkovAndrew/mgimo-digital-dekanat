## Дополнительно для Claude Code

- Codex вызывай из корня проекта, продолжая его постоянную сессию:
  `codex-ask resume 01a1bfe2-fee7-71d1-8d1a-66ab06413479 "<задача>"`
  (`--last` допустим, пока в `codex-ask sessions` одна сессия). Новую сессию не создавай.
  Ответ сохраняй в `docs/ai-log/codex/NN-тема.md` через `-o`.
- Не отправляй в сессию Codex несколько запросов одновременно.
- Указывай Codex, какой дифф или коммит проверять; после новых изменений
  соответствующая часть ревью устаревает.
- Отправляй Codex на ревью план перед крупной функцией, любые изменения авторизации
  и доступа к данным, финальный дифф перед коммитом.
- Замечания Codex сверяй с ТЗ и текущим диффом; правки выполняет Claude,
  если человек явно не поручил иное.
- После каждого значимого шага добавляй запись в `docs/ai-log/JOURNAL.md`.
