# Промо-ролик кабинета

37 секунд, 1920×1080, 60 к/с, H.264 High 4.2 (MP4). Сценарий капитана: телефон парит на размытом фоне и листает кабинет;
камера поворачивается и приближается, подписи перечисляют функции; заявка вылетает из телефона и прилетает
на ноутбук уже одобренной («На любом устройстве»); свет гаснет, включается тёмная тема; финальная карточка
с адресом и дисклеймером.

Всё на экранах — настоящие снимки локального кабинета (Алина, демо-данные), ответ помощницы — настоящий ответ
GigaChat. Модели телефона и ноутбука собраны из примитивов three.js, без чужих моделей, логотипов и узнаваемых
деталей конкретных производителей.

## Как собрать

```bash
cd video && npm install
# 1. Снимки (кабинет запущен: npm run dev в корне). Пароли — только из окружения.
PW_A=… node capture.mjs phone            # кадры телефона → captures/phone/
PW_A=… PW_STAFF=… node capture.mjs flow  # ПИШЕТ В БД: Алина подаёт справку, деканат отмечает «Готово»
# повтор без новой заявки: REQUEST_ID=<id> … node capture.mjs flow
# 2. Проверочные кадры и ролик
node render.mjs stills 1,9,23.6,26.5,31.7,35   # → out/stills/
node render.mjs video                           # → out/dekanat.mp4, ~8 мин на CPU
node render.mjs frames dekanat.mp4 1,26.5       # кадры из готового MP4 → out/frames/
python3 check-mp4.py out/dekanat.mp4            # кодек, размер, кадры, длительность
```

## Как устроено

- `capture.mjs` — Playwright: телефон 390×800 при DPR 2, 60 к/с, прокрутка задаётся по кадрам (плавно и одинаково
  при каждом запуске). Браузер прокручивает на целые пиксели — дробная часть добирается сдвигом `<main>`, иначе на
  разгоне и торможении страница стоит и прыгает; смещения по кадрам — в `captures/phone/<экран>/scroll.json`; ноутбук 1280×800 при DPR 2 до и после одобрения, светлая и тёмная тема.
- `scene/` — three.js: `models.js` (телефон, ноутбук, карточка, тени), `screens.js` (экраны: строка состояния,
  сдвиг страниц, касание, подсветка строки, круговое включение тёмной темы), `overlay.js` (фон, подписи, знак
  University, финальная карточка), `main.js` (таймлайн, камера по ключам, рендер и кодирование).
- Кодирование — WebCodecs `VideoEncoder` (avc1 High 4.2: 1080p при 60 к/с) в самом Chromium, упаковка — `mp4-muxer` (MIT).
  ffmpeg не нужен; GPU тоже: рендер идёт в SwiftShader, ~200 мс на кадр.
- Зависимости: three (MIT), mp4-muxer (MIT), playwright (Apache-2.0); шрифт Onest (OFL) — из `assets/fonts/onest`.
