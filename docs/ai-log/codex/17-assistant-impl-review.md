1. **P2 — обход белого списка ссылок.** [answer.ts:18](/home/acid/projects/MGIMO/src/lib/assistant/answer.ts:18): сервер разбирает метки до 120 символов, клиент в строке 27 — без такого ограничения. Воспроизведено: метка из 121 символа со ссылкой `/requests/not-mine` проходит санитайзер и становится кликабельной. Аналогичное расхождение есть для длинных href. 2. **P2 — история не привязана к пользователю.** [assistant/page.tsx:11](/home/acid/projects/MGIMO/src/app/(cabinet)/assistant/page.tsx:11), [chat.tsx:52](/home/acid/projects/MGIMO/src/app/(cabinet)/assistant/chat.tsx:52): очистка происходит только при размонтировании. После смены аккаунта в другой вкладке старый Chat может отправить историю A с новой сессией B; `router.refresh()` также сохраняет клиентский state без смены ключа. Нужны привязка диалога к `userId`, проверка несовпадения владельца перед вызовом модели и очистка/отмена при смене сессии.

3. **P2 — отменённый запрос может продолжать ждать слот, дедлайн 25 секунд не гарантирован.** [limits.ts:30](/home/acid/projects/MGIMO/src/server/ai/limits.ts:30): подписка на `abort` не обрабатывает уже отменённый сигнал. Воспроизведено: такой запрос остаётся в очереди до передачи слота либо ещё 20 секунд. Это возможно после долгого `buildMyContext()`. В [route.ts:92](/home/acid/projects/MGIMO/src/app/api/assistant/route.ts:92) аналогично не проверяется начальное состояние `req.signal`. Проверять отмену до ожидания и перед `run`; сбор контекста тоже должен прекращать ожидание по общему дедлайну.

4. **P2 — допустимая история превышает лимит тела.** [chat.tsx:76](/home/acid/projects/MGIMO/src/app/(cabinet)/assistant/chat.tsx:76): обрезание только до 12 реплик не учитывает UTF-8. Девять допустимых реплик — пять русских вопросов по 1000 символов и четыре ответа по 2000 — дают **26 295 байт**, сервер допускает 24 КиБ. Получается 413, повтор отправляет тот же запрос. Убирать старые пары сообщений по фактическому размеру сериализованного тела.

5. **P2 — у поля ввода отсутствует видимый фокус.** [chat.tsx:187](/home/acid/projects/MGIMO/src/app/(cabinet)/assistant/chat.tsx:187): `outline-none` перекрывает базовое кольцо; замены через `focus-visible` или `focus-within` нет. Постоянная рамка формы не показывает изменение фокуса. Убрать подавление либо добавить явный индикатор.

6. **P3 — автопрокрутка игнорирует reduced motion.** [chat.tsx:63](/home/acid/projects/MGIMO/src/app/(cabinet)/assistant/chat.tsx:63): явное `behavior: "smooth"` действует независимо от CSS-медиазапроса. Использовать `auto` при `prefers-reduced-motion`.
