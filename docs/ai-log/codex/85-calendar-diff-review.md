- **P2 — гонка восстановления хеша и ротации.** [calendar.ts:47](/home/acid/projects/MGIMO/src/server/dal/calendar.ts:47). После смены секрета `getMyFeed` может прочитать версию 1, параллельная ротация выпустить версию 2, затем `update` перезапишет её хеш токеном версии 1. Обе ссылки перестают работать. Воспроизвёл в памяти. Нужен CAS по прочитанной версии/хешу с повторным чтением либо общая транзакционная блокировка.

- **P2 — тёмная тема ломает цвета печати.** [page.tsx:52](/home/acid/projects/MGIMO/src/app/print/schedule/page.tsx:52). Фон становится белым, но тёмные токены текста сохраняются: `--ink: #eceef2`, `--ink-2: #a7aec4`. Расписание и дисклеймер оказываются светлыми на белом. Для печати переопределить весь используемый набор токенов на светлый.

- **P3 — `METHOD:PUBLISH` не согласован с HTTP-заголовком.** [ics.ts:60](/home/acid/projects/MGIMO/src/lib/calendar/ics.ts:60). При наличии `METHOD` RFC требует соответствующий параметр `method=PUBLISH` в `Content-Type`; сейчас его нет во всех трёх ответах ICS. Добавить параметр либо убрать `METHOD` для обычной календарной выгрузки. [RFC 5545 §8.1](https://www.rfc-editor.org/rfc/rfc5545.html#section-8.1).
