**2. Правила ИТМО**

**БаРС.** В [инструкции учебного департамента](https://edu.itmo.ru/files/23), стр. 1–2, указано:

- 100 основных баллов и до 3 дополнительных;
- текущий контроль даёт **60–80**, промежуточная аттестация — **20–40** баллов; распределение задаёт программа дисциплины;
- баллы собираются за контрольные точки: лабораторные, тесты, работы и другие задания;
- для положительной аттестации нужны **минимум 60 баллов и все ключевые контрольные точки**.

Шкала из этой инструкции:

| Баллы | Оценка | ECTS |
|---|---|---|
| меньше 60 | 2 | FX |
| 60–67 включительно | 3 | E |
| больше 67, до 74 включительно | 3 | D |
| больше 74, до 83 включительно | 4 | C |
| больше 83, до 90 включительно | 4 | B |
| больше 90, до 103 включительно | 5 | A |

Для обычного зачёта — от 60, при выполнении обязательных точек.

**Единого числового порога допуска к экзамену не нашёл.** Не следует превращать «60 для положительного результата» в «60 для допуска». В журнале у контрольных точек есть собственные минимумы; ключевые точки обязательны. [Инструкция студента](https://edu.itmo.ru/files/708), стр. 5–6.

Есть расхождение: [страница международного обмена](https://int.itmo.ru/en/exchange) приводит другие границы ECTS — например, B от 83. Для University рекомендую единую шкалу из инструкции выше с пометкой о демонстрационных правилах.

**Физкультура.** Для стандартной траектории [памятка спортивного клуба](https://kronbars.itmo.ru/students) устанавливает:

- **100 баллов за семестр**, из них минимум **60 за тренировки**;
- тренировка — **5 баллов**;
- следовательно, минимум **12 тренировок** с дополнительными баллами либо **20**, если набирать только посещениями;
- дополнительные спортивные активности — до 40 баллов; есть нормативы и специальные форматы.

Запись: `my.itmo → Спорт → Запись на секции → комплекс → секция`. Для свободного посещения можно выбирать занятия еженедельно либо записываться до конца семестра; ограничения — **до двух занятий в неделю и 25 в семестр**. Пропуск без отмены расходует доступную запись. Единого подтверждённого часа открытия записи не нашёл. Для освобождений и специальных проектов действуют отдельные правила.

В интерфейсе лучше показывать **«65/100 баллов; тренировки 45/60 обязательных»**, отдельно — будущие записи. Бронирование ещё не означает посещение.

**Коды групп.** Официальное [объяснение нумерации 2015 года](https://news.itmo.ru/ru/archive/news/5053/) задаёт структуру:

`буква факультета | уровень подготовки | курс | номер группы | необязательный строчный суффикс сетевой программы`.

Для `P3212` это разбиение `P | 3 | 2 | 12`: факультет, уровень, второй курс, группа 12. Уровень `4` как магистратура подтверждён прямо; актуальную официальную таблицу соответствий, включая `3 = бакалавриат` и нынешнее значение `P`, получить не удалось. Для University такую расшифровку можно принять как **собственное демо-правило**, но хранить курс и факультет отдельными полями.

**3. Концепция и распределение мест**

Связка сильна, если демонстрация показывает завершённый сценарий: **выбрал спорт → получил место → занятие появилось в расписании → виден переход → посещение увеличило прогресс зачёта**.

Главные слабые места:

- **Расстояние по прямой не определяет время перехода:** реки, входы, транспорт и переодевание меняют результат. Для прототипа нужна небольшая вручную проверенная матрица времени между площадками с запасом.
- Формулировку «в ИТМО нет карт» использовать нельзя: официальный факультетский справочник уже упоминает **Itmo.map**. Проблема команды — связь сервисов в конкретном сценарии. [Источник](https://physics.itmo.ru/en/node/34814).
- «Честная запись» требует опубликованных правил и понятного отказа. Алгоритм не устранит нехватку мест; кабинет должен показывать и этот дефицит.

Предлагаю **недельное распределение по случайной очереди, в два прохода**. Это правила University, не описание существующей системы ИТМО.

1. **До общего дедлайна** студент ранжирует приемлемые занятия. Время подачи предпочтений не влияет на приоритет.
2. Система проверяет каждый слот относительно **предыдущего и следующего события**: пары не пересекаются, хватает времени на оба перехода и переодевание. Недоступность объясняется числами.
3. Для недели фиксируется случайный порядок студентов. Для воспроизводимости сохраняются seed жеребьёвки, версия расписания и предпочтения; повторный запуск даёт тот же результат.
4. **Первый проход:** каждому выдаётся его наиболее предпочтительный доступный слот, максимум один.
5. **Второй проход:** распределяются вторые занятия, только после обработки всех в первом проходе. Проверяются также конфликты с уже выданной физкультурой.
6. **Лист ожидания** обслуживает недополучивших недельную квоту в сохранённом порядке. Освободившееся место автоматически получает следующий подходящий кандидат из указавших этот слот; повторная гонка кликов не возникает.
7. Результат записывается атомарно, с защитой от превышения вместимости и повторного запуска. Перенос пары вызывает повторную проверку и уведомление о конфликте.

Студенту показываем: **«Первый выбор заполнен; назначен второй»**, **«Переход: доступно 10 минут, заложено 25»**, **«В очереди перед вами 3 подходящих кандидата»** — без чужих имён.

Для 12 дней ограничил бы демонстрацию несколькими корпусами, одной неделей и небольшим набором спортивных занятий. Такой алгоритм объясним и реализуем; максимальное число удовлетворённых предпочтений он не гарантирует.
