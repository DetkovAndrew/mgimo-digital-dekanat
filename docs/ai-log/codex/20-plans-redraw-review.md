> git diff HEAD поверх eea9761: схемы «по мотивам» реальных планов (мини-язык аудиторий, крылья под углом, веер лекционных, ротонда), новая отрисовка, удаление исчезнувших аудиторий в sync-rooms. Проверить безопасность удаления, стабильность id, геометрию и доступность. Ничего не править.

## Ответ Codex

1. **P1 — возможна потеря новой брони при онлайн-синхронизации.** [sync-rooms.ts:31](/home/acid/projects/MGIMO/scripts/sync-rooms.ts:31): `DELETE` может увидеть отсутствие броней, затем ждать блокировку `bookRoom`. После подтверждения брони удаление продолжится, а `ON DELETE CASCADE` удалит её вместе с комнатой. Это риск при исключении бронируемой аудитории; наличие одного `deleteMany` его не устраняет из-за снимков [READ COMMITTED](https://www.postgresql.org/docs/18/transaction-iso.html). Сначала закрывать бронирование, затем заново проверять зависимости; для RoomBooking полезна страховка `RESTRICT`.

2. **P2 — проверка «есть занятия» выполняется после их отвязки.** [sync-rooms.ts:24](/home/acid/projects/MGIMO/scripts/sync-rooms.ts:24): исчезнувшая аудитория получает `target = null`, её занятия теряют `roomId`, после чего `lessons: { none: {} }` позволяет удалить Room. При отсутствии броней занятая аудитория фактически считается пустой. Для офлайн-занятия без нового соответствия сохранять прежнюю связь либо останавливать синхронизацию с ошибкой.

3. **P3 — номера на телефоне становятся практически нечитаемыми.** [campus-map.tsx:114](/home/acid/projects/MGIMO/src/components/campus-map.tsx:114): при ширине содержимого 328 px размер `9.5` в новом `viewBox` превращается примерно в **5,6–6 px**. Полный список сохраняет доступность, но для самой схемы нужны увеличение масштаба/минимальной ширины или более крупные подписи.

ID всех **девяти прежних бронируемых комнат сохранены**. Все 15 явных ссылок на аудитории схем из seed разрешаются. Пересечений аудиторий между собой и выхода их полигонов за `viewBox` расчёт не выявил. Файлов `maps/` среди отслеживаемых нет.

Гонка удаления оценена статически; БД и браузер не запускал.
