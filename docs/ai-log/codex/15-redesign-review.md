## Ответ Codex

**P1 не нашёл.**

1. **P2 — глобальный CSS перекрывает исправления фокуса.** [globals.css:159](/home/acid/projects/MGIMO/src/app/globals.css:159) находится вне `@layer`, поэтому выигрывает у Tailwind-классов `focus-visible:outline-focus-on-brand` и `focus-visible:-outline-offset-2`. На выбранном дне расписания кольцо совпадает с фоном в светлой теме; у ссылки сводки обрезается контейнером. Перенести базовое правило в `@layer base`, затем проверить клавиатурой новые элементы.

2. **P2 — после окончания сессии сводка продолжает показывать «Сессия идёт».** [grades/page.tsx:76](/home/acid/projects/MGIMO/src/app/(cabinet)/grades/page.tsx:76): любой `left <= 0` означает «идёт», без проверки `sessionEndsOn`. Это проявится и при наличии только прошлых семестров. Нужны отдельные состояния «до», «идёт», «завершена».

3. **P2 — «Работ сдано» считает любой выставленный результат успешной сдачей.** [grades/page.tsx:67](/home/acid/projects/MGIMO/src/app/(cabinet)/grades/page.tsx:67): результат с `grade: 2`, `passed: false` или нулём баллов тоже увеличивает счётчик. Для текущей модели точнее назвать показатель «Работ оценено»; успешную сдачу без отдельного правила определить нельзя. Итоговая аттестация соответствующего `controlForm` исключается правильно.

4. **P2 — граница ленты вычисляется по последней начавшейся паре вместо самого позднего окончания.** [next-lesson.tsx:29](/home/acid/projects/MGIMO/src/components/next-lesson.tsx:29). Для занятий 18:00–22:00 и 19:00–20:00 шкала закончится в 20:00, первый отрезок выйдет до **116,7%**. Аналогично неверно «до …» в строке 100. Использовать максимум `endsAt` среди занятий дня.

5. **P2 — маркер «сейчас» и оставшиеся минуты застывают до следующего рендера страницы.** [next-lesson.tsx:31](/home/acid/projects/MGIMO/src/components/next-lesson.tsx:31), [строка 63](/home/acid/projects/MGIMO/src/components/next-lesson.tsx:63): серверный `now` не обновляется. При оставленной открытой вкладке законченная пара продолжает «идти». Нужен периодический пересчёт времени и выбор следующей пары либо явно обозначенный снимок времени.

6. **P3 — на пустой неделе якоря ведут к отсутствующим элементам.** [schedule/page.tsx:70](/home/acid/projects/MGIMO/src/app/(cabinet)/schedule/page.tsx:70): навигация выводится всегда, а секции с целевыми ID — только при `lessons.length > 0` в строке 90. Оставить пустые секции дней либо скрывать полосу на полностью пустой неделе.

7. **P3 — новые основные карточки расходятся с правилом радиусов.** [next-lesson.tsx:60](/home/acid/projects/MGIMO/src/components/next-lesson.tsx:60), [grades/page.tsx:74](/home/acid/projects/MGIMO/src/app/(cabinet)/grades/page.tsx:74), [sport/page.tsx:24](/home/acid/projects/MGIMO/src/app/(cabinet)/sport/page.tsx:24): `rounded-3xl` даёт 24 px при требовании 16 px. Либо `rounded-2xl`, либо явное исключение для главных карточек в AGENTS.md.

`xl:-mx-40` при 1280–1400 px помещается: расширенный блок 960 px, свободное пространство справа от панели — 1040–1160 px. MSK-арифметика суток корректна; отменённые пары исключены из ленты, маркер другого дня скрывается. `aside` на `/login` и `/staff` расположен корректно, вне `main`.
