1. **P2 — изменить обещание «подлинности».** [План:46](/home/acid/projects/MGIMO/docs/plans/certificates.md:46): QR подтверждает существование записи в демо-реестре, **не неизменность предъявленного PDF**. Заменить «Справка подлинная» на «Демонстрационный документ найден». В PDF и проверке явно: «Не подтверждает обучение в реальном вузе. Юридической силы не имеет». Водяной знак снижает риск путаницы, но гарантировать невозможность подделки нельзя. Не добавлять имитацию печати, подписи или реквизиты реального вуза.

2. **P2 — считать токен секретом доступа.** [План:36](/home/acid/projects/MGIMO/docs/plans/certificates.md:36): он открывает сведения о студенте, даже сокращённые. 128 случайных бит достаточно против угадывания; открытое хранение для прототипа допустимо как осознанный компромисс. Убрать объяснение «показывает меньше PDF — значит безопасен». Не передавать токен в снимок помощника, уведомления, общий список заявок и логи.

3. **P2 — отдельный публичный DTO проверки.** Возвращать из DAL только перечисленные публичные поля, собранные **из снимка**, без `content`, связанной заявки и профиля целиком. Сокращать ФИО на сервере, не скрывать лишнее CSS. Исключение AGENTS.md должно явно разрешать доступ любому обладателю ссылки; рядом с копированием ссылки сообщить об этом студенту.

4. **P2 — дополнить защиту открытого маршрута.** [План:45](/home/acid/projects/MGIMO/docs/plans/certificates.md:45): добавить `Referrer-Policy: no-referrer`, включая исключение из текущего правила Caddy; не использовать внешние ресурсы и аналитику. Задать `no-store` и запрет индексации также в приложении, для успешных и ошибочных ответов. Ошибки — без токена, снимка и SQL. Проверить настоящий HTTP 404. Небольшой лимит запросов нужен против нагрузки на БД, независимо от невозможности перебрать токены.

5. **P2 — зафиксировать атомарность выпуска.** В одной транзакции и через один `tx`: повторная проверка факультета и текущего статуса → проверка `study_certificate` и `payload.format === "electronic"` → валидация снимка → документ → событие → уведомление. Ошибка любого шага должна откатывать всё. `unique(requestId)` подходит; PDF рендерить вне удерживаемой блокировки. Владельца через заявку определять правильно, но отдельно закрепить неизменность её `studentId` после выпуска.

6. **P2 — описать жизненный цикл.** Сейчас отзыв после READY уже запрещён — сохранить и протестировать. При READY → DONE документ остаётся доступен; повторный READY не меняет номер, токен или снимок. Для старых READY/DONE без документа выбрать явный backfill либо сообщение «Документ не выпускался»; GET скачивания ничего не создаёт. Проверить гонку отмены студентом против READY сотрудника: документ существует только при победившем выпуске.

7. **P2 — исправить обещание одинакового PDF.** [План:65](/home/acid/projects/MGIMO/docs/plans/certificates.md:65): одного `CreationDate` недостаточно — есть `ModificationDate`, шаблон, шрифты и адрес проверки. Хранить версию шаблона и URL проверки на момент выпуска; старый домен продолжать обслуживать при смене адреса. Для прототипа проще обещать неизменность данных, а не байтов файла. Если нужны одинаковые байты — сохранять готовый PDF. [API метаданных pdf-lib](https://pdf-lib.js.org/docs/api/classes/pdfdocument#setmodificationdate).

8. **P2 — расширить тесты содержимого и приватности.** Добавить: сотрудник другого факультета; сотрудник на PDF-endpoint — 403; несуществующая заявка; rollback выпуска при ошибке; изменение профиля после выдачи; одинаковый публичный результат для анонима/A/B. Проверять отсутствие запрещённых полей и токена в HTML/RSC/ошибках, а не только в объекте DAL. Для PDF нужны длинные кириллические строки, переносы и управляющие символы, отсутствие наложения на QR и декодирование QR после рендеринга — одного `PDFDocument.load` недостаточно.

9. **P3 — стек подходит, упаковку уточнить.** `pdf-lib` + зарегистрированный `@pdf-lib/fontkit` подходят для кириллицы. Onest распространяется под OFL, но Google Fonts поставляет variable-файл `Onest[wght].ttf`: зафиксировать проверенные файлы/инстансы 400/600 и их происхождение. Добавить TTF и OFL в tracing PDF-маршрута, явно использовать Node runtime. Кешировать можно байты шрифтов, не общий `PDFDocument` с личными данными. Проверить скачивание именно из standalone под пользователем `node`. [Fontkit](https://pdf-lib.js.org/docs/api/classes/pdfdocument#registerfontkit), [Onest](https://raw.githubusercontent.com/google/fonts/main/ofl/onest/METADATA.pb), [OFL](https://raw.githubusercontent.com/google/fonts/main/ofl/onest/OFL.txt).
