## DuckDNS

Проверены официальные FAQ, спецификация и условия DuckDNS, документация Let's Encrypt.
Результат добавлен в [subdomain.md](../../research/subdomain.md).
Для краткого конкурсного прототипа сервис приемлем после проверки реального адреса
и HTTPS из РФ, но гарантии непрерывной работы у сервиса нет. Учитываем обновление IP,
защиту токена и отдельное получение сертификата. DNS не решает блокировки самого VPS.

Открыта видимая встроенная вкладка `https://www.duckdns.org/`. На ней только кнопки
входа Google/GitHub и других провайдеров, активного входа пользователя нет.
Пользователю передан запрос выполнить вход; пароль/токен не запрашивался.
Имя `university-dekanat.duckdns.org` пока **не зарегистрировано**, свободность
через авторизованный интерфейс не проверена. Изменений DNS и покупок нет.
