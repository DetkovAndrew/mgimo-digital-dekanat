**P1 не вижу:** доступ только по сессии и предложенные заголовки отдачи — разумная основа. До реализации уточнить:

1. **P2 — magic bytes и размеры заголовка не подтверждают корректность всего изображения.** [avatars.md:10](/home/acid/projects/MGIMO/docs/plans/avatars.md:10). Клиентский canvas обходится прямым запросом. Определить проверку повреждённых контейнеров, нулевых размеров, разных вариантов WebP; запретить APNG/анимированный WebP, чтобы ограничение 512×512 не скрывало множество кадров. Предпочтителен готовый серверный декодер/перекодировщик с допустимой лицензией либо существенно более узкий набор форматов. [Рекомендации OWASP](https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html).

2. **P2 — нет ограничений частоты и общего тела запроса.** [avatars.md:10](/home/acid/projects/MGIMO/docs/plans/avatars.md:10): 200 КиБ на File не ограничивают multipart до его разбора. Задать лимит запроса на уровне Next/Nginx и лимиты загрузки/удаления на студента: частые перезаписи `bytea` нагружают БД и WAL. Проверять размер до `arrayBuffer()`, ограничить исходное изображение перед декодированием в браузере.

3. **P2 — явно исключить оптимизатор `next/image`.** [avatars.md:13](/home/acid/projects/MGIMO/docs/plans/avatars.md:13): использовать обычный `<img>` либо `Image unoptimized`. Стандартный оптимизатор не передаёт авторизацию к исходному URL и имеет отдельное кеширование; приватный `/api/avatar` через него работать корректно не будет.

4. **P2 — `?v=updatedAt` недостаточно для смены аккаунта.** [avatars.md:17](/home/acid/projects/MGIMO/docs/plans/avatars.md:17): уже показанное изображение не исчезает из DOM из-за `no-store`, а layout может сохраняться. Привязать отображение к актуальной сессии, очищать старое фото при смене пользователя. Расширить тест: **оба** студента имеют разные аватары, переход A→B→A; добавить отсутствие сессии, удаление, ошибки загрузки и `no-store` на ошибочных ответах.

5. **P3 — зафиксировать ограничения демо.** Для скриншотов и тестовых аккаунтов использовать сгенерированные лица/иллюстрации; в форме напомнить о вымышленных данных. Реальные фотографии участников расходятся с правилами проекта.

Штатную Origin-защиту Server Actions сохранить; MIME определять сервером, имя файла не использовать в заголовках или путях. SVG отклонять независимо от переданного `File.type`.
