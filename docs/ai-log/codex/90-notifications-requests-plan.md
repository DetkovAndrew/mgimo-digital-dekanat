План подходит, P1 не вижу. Что уточнить до реализации:

1. **P2 — «Вернуть» должно отменять конкретное удаление.** Одного `count` недостаточно: часть строк уже могла быть скрыта другим экспертом. Возвращай фактически изменённые ID и метку операции (`hiddenAt`); восстановление — только при совпадении метки. Иначе запоздалое «Вернуть» отменит более новое удаление. Обычных атомарных UPDATE достаточно, отдельные блокировки не нужны.

2. **P2 — привязать список и Undo к аккаунту.** Глобальный `Toaster` сейчас не привязан к владельцу. После смены аккаунта старый callback может восстановить доставку уже другого студента, если уведомление общее. Сбрасывать выбор/тосты при смене пользователя; сервер перед восстановлением сверяет владельца операции с сессией.

3. **P2 — поправить A/B-тест общего объявления.** У него один `notificationId`, но две доставки. Если Алина скрывает его, ожидается `count=1`, её доставка скрыта, Тимура — нет. `count=0` проверяйте на уведомлении **только Тимура**. Добавить повторное удаление, устаревшее Undo и отзыв объявления перед Undo — восстановление не должно создавать удалённые доставки.

4. **P2 — интерактивный тост требует адаптации.** Сейчас контейнер `pointer-events-none`, срок — 3,5 секунды: кнопка окажется недоступной без изменений. Дать действию `pointer-events-auto`, цель ≥44 px, достаточное время и паузу исчезновения при фокусе/наведении. Ошибка восстановления должна показываться отдельно.

5. **P2 — «Выбрать все» сейчас означает максимум 100 показанных.** `listMyNotifications` ограничен сотней. Назвать «Выбрать все показанные»; после удаления подгружать оставшиеся. При ошибке не возвращать весь старый снимок поверх новых данных — откатывать только свою операцию.

6. **P2 — обновление списка заявок и счётчика.** После отмены/ответа инвалидировать `/requests/my` и общий блок вкладок. Сейчас эти действия обновляют только `/requests/[id]`. `READY` оставить среди активных: документ готов, но заявка ещё не завершена.

7. **P3 — жесты делать последними.** Сначала кнопка «Выбрать» и массовое удаление. Для жестов явно предусмотреть отмену удержания при прокрутке, `pointercancel`, отпускании и размонтировании; после долгого нажатия тоже подавлять переход по ссылке.

8. **P3 — миграция и маршруты.** Для заявленного индекса нужен ещё `CREATE INDEX`, не только `ADD COLUMN`. Каталог всегда по `/requests` — предсказуемое решение; вкладка «Мои заявки» со счётчиком сохранит доступ к статусам за одно касание. Неизвестный переданный `type` лучше давать как 404, отсутствие `type` — редиректить в каталог.
