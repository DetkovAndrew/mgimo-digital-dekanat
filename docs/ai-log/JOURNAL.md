**4. Окружение (ручной этап + ошибка ИИ).**
- Node.js в среде не было. Claude поставил Node LTS в домашнюю папку пользователя, без sudo.
  Сверил контрольную сумму SHA-256.
- На диске C: было занято 99% места. Команда вручную очистила диск.
- `git init` и `npm install` в `C:\MGIMO` падали с `EPERM: chmod`. Claude сначала обошёл это:
  вынес `.git` на диск WSL. Потом предложил перенести весь проект.
  **Команда отклонила перенос.** Администратор вместо этого исправил подключение диска:
  отдельное представление DrvFS с правами пользователя среды.
  После перезапуска Claude перепроверил `chmod`, git и `npm install` с bin-ссылками — всё работает.
  Урок: менять место проекта ради обхода ограничения среды — плохой путь,
  сначала нужно сообщить людям и проверить, можно ли исправить саму причину.
