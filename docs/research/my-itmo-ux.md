# Исследование: как выглядит my.itmo (скриншоты капитана, 10.11.2026)

10 скриншотов десктопной версии лежат в `docs/research/screenshots/` (в `.gitignore`: на них реальные
личные данные, а в «Персоналиях» — телефоны и почты других людей). Здесь — только выводы, без
персональных данных. Имена реальных преподавателей со скриншотов в seed **не используем**.

## Что увидели

| Экран | Как устроено | Чего не хватает |
|---|---|---|
| **Главная** | Три виджета: расписание на сегодня, зачётка (список дисциплин + тип контроля), финансы (сумма скрыта). Много пустого места | Нет ответа «что мне сделать сейчас»: ближайшая пара, дедлайны, статусы заявок, изменения |
| **Расписание** | Недельная сетка-календарь, цвет по типу занятия, у пары: время, предмет, преподаватель, аудитория + полный адрес с литерой. Переключатель неделя/месяц, «Сегодня» | Адрес — просто текст: нет карты, маршрута, предупреждения о переходе между литерами/корпусами. На 360 px сетка 7 колонок не помещается |
| **Зачётка** | Таблица: предмет, тип контроля, **баллы**, итоговая оценка, дата экзамена; выбор программы и семестра | Баллы почти везде пустые, одно число без максимума («18» — из скольких?), нет порогов 60/67/74/84/91, нет «сколько не хватает» |

| **Мой спорт** | Кольцо «баллы за посещения» (5), отбор в секции, группа здоровья, инструктаж, календарь «Мои секции», кнопка «Записаться» | Не видно цели (60 за тренировки из 100), темпа («нужно ещё N тренировок до конца семестра»), связи с расписанием пар |
| **Финансы** | Стипендия по месяцам, назначенная стипендия, итог за всё время | Вне ядра ТЗ; можно одной карточкой |
| **Персоналии** | Поиск по ~77 тыс. людей с телефонами и почтами | **Приватность**: личные контакты видны всем. У нас — только служебные контакты деканата/преподавателей |
| **Заявки и очереди** | Вкладки «Заявки / Мои заявки / Очереди», поиск, ~30 видов по разделам (электронные справки, учёба, заказ документов, академ…) | Каталог длинный; статус — отдельной вкладкой; истории и диалога с деканатом не видно |
| **Сервисы** | Плитки: **Навигатор (карта корпусов и маршруты)**, общежитие, бронирование помещений, ИУП, здоровье… | Навигатор — отдельный сервис, **не связан с расписанием** — это ровно боль команды |
| **Ассистент «Тим»** | Чат-панель с подсказками «Чем заняться на неделе?», «Записаться на спорт» | ИИ-помощник уже есть. Нам он не обязателен; если делать — отвечать по данным кабинета со ссылками, не «чат ради чата» |

## Что берём (структура, не внешний вид)

1. Боковое меню разделов на десктопе; разделы «Сервисы» и «Заявки» с поиском и категориями.
2. Каталог заявок с поиском и группами + вкладка «Мои заявки».
3. Неделя в виде сетки на десктопе; на телефоне — список по дням (у нас уже так).
4. Кольцо прогресса для баллов — но с целью и порогами.

## Что делаем лучше — аргументы для жюри

1. **«Сегодня» вместо витрины виджетов**: следующая пара с маршрутом, что изменилось, ближайшие
   дедлайны, заявки, требующие действия.
2. **Расписание + Навигатор в одном месте**: у пары кнопка маршрута, предупреждение о переходе
   между корпусами/литерами за перерыв.
3. **Понятные баллы**: «54 из 100 · до зачёта 6 · ближайшая возможность — лабораторная 3, до 18.11»,
   пороги шкалы на полосе.
4. **Спорт с целью и честной записью**: «45 из 60 за тренировки · нужно ещё 3 · в неделю ≈ 1»,
   жеребьёвка вместо гонки, запись сразу в расписании.
5. **Заявки с историей и диалогом** (уточнение от деканата → ответ студента).
6. **Приватность по умолчанию**: никаких открытых телефонов и почт студентов.
7. **Мобильная версия как основная** (скриншоты — только десктоп).

## Внешний вид

Не копируем: у my.itmo белый фон, синие акценты, фирменный красно-синий знак и шрифт. University
делает собственный стиль и знак, чтобы прототип не выглядел официальным сервисом (требование ТЗ).
