# Хостинг для конкурсного прототипа

Проверено по официальным страницам и браузерному калькулятору Selectel 11.11.2026.
Ничего не заказано и не оплачено. Финальную доступность тарифа и сумму перед заказом
перепроверяет капитан. Прежнее решение «пока используем локальный запуск» сохранено.

## Общие условия расчёта

21 день = 504 часа непрерывной работы. Ориентир: Ubuntu LTS, 2 vCPU,
**4 ГБ RAM предпочтительнее 2 ГБ** для Next.js + PostgreSQL + ОС, SSD 30–50 ГБ,
публичный IPv4, Docker Compose и Nginx. Это инженерная оценка, нагрузочный тест не выполнен.
Сборку лучше делать заранее или проверять отдельно: её расход памяти выше обычной работы.
Локальную LLM в эти 4 ГБ не закладываем; ИИ вызывается через серверный API.

Месячную цену ниже пересчитываем как `цена × 21/30` **только для бюджетной оценки**.
Фактический почасовой тариф, IPv4, диск, резервные копии и минимальное пополнение
могут изменить сумму. Период оплаты должен покрывать работу до конца 28.11 МСК.

## Адрес и HTTPS без покупки домена

Уточнение от 11.11: [выбор бесплатного поддомена и платная альтернатива](subdomain.md).
Рекомендация для читаемого бесплатного имени — DuckDNS; регистрация ещё не выполнена.

Можно использовать `<публичный-ip>.sslip.io`: сервис разрешает имя с IP в этот IP [D1].
Он предоставляет DNS, а не сертификат и не хостинг. HTTPS нужно отдельно выпустить
и настроить на Nginx, например через ACME HTTP-01; проверить 80/443 и продление.
Наличие DNS-имени не доказывает доступность сайта с российских операторов.

## Рекомендация

Сначала проверить уже оплаченный британский VPS: если ресурсов хватает, ссылка стабильно
работает из РФ, а API ИИ доступен, дополнительные расходы могут не понадобиться.
Это условная рекомендация: IP, конфигурация и доступ к серверу в репозитории отсутствуют.

Если UK-вариант не проходит сетевую проверку, первым проверить **Yandex Cloud с грантом**:
потенциально он покрывает период конкурса, но окончательная сумма с диском/IP должна
помещаться в остаток гранта. Если аккаунт не подходит для гранта, сравнить окончательные
котировку Timeweb Premium с полученной котировкой Selectel; текущих данных недостаточно, чтобы
честно объявить самого дешёвого. Покупает и выбирает капитан.

## Проверка британского VPS — требуется команда

1. Капитан сообщает публичный URL/IP и характеристики (без паролей в Git).
2. NursuUwU открывает HTTPS-ссылку без VPN с домашнего и мобильного интернета,
   по возможности с двух операторов. Проверяет вход, заявку и перезаход.
3. Капитан/разработчик делает с самого VPS авторизованный тест доступных моделей
   и короткий запрос к выбранному API. Один ответ 401 без токена проверяет лишь сеть,
   а не работоспособность интеграции. Сертификаты проверять штатно, TLS не отключать.
4. В документации GigaChat целевой API теперь `https://api.giga.chat` [G1]; старый адрес
   может сохраняться для прежних подключений. Условия для новых платящих клиентов
   отличаются от старых: quickstart отсылает на cloud.ru [G2]. Проверить конкретный аккаунт.
   Доказательства приёма запросов с **данного UK-IP** пока нет.
