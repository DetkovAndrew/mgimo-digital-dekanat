# Материалы NursuUwU: исследование, eval, бренд и подготовка сдачи

Подготовлены материалы для семи задач NursuUwU: анкета без вымышленных результатов,
30 проверочных вопросов для будущего агента с локальным эталоном, сравнение российских
VPS с источниками и котировкой Selectel, аудит имён, сценарии телефонов и видео,
редактируемый отчёт и семистраничный PDF-черновик.

Собственный SVG-знак и иконки подключены к входу/навигации, favicon и manifest.
В seed заменены два имени с совпадениями сотрудников вузов и исправлены тексты,
которые обещали несуществующий PDF, неясную практику или противоречивую дату публикации.
Для воспроизводимого запуска на Windows исправлена локаль PostgreSQL;
typecheck теперь сначала генерирует типы маршрутов Next.js.
