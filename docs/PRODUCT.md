# Продукт: «Цифровой деканат будущего»

Черновик. Гипотезы о реалиях МГИМО помечены «нужно подтвердить» — проверяем у однокурсников.

## Проблема

Учебная жизнь разбросана: расписание на сайте, оценки в отдельной системе, справки —
через очередь в деканате, объявления — в чатах и на почте. С телефона найти нужное трудно.

## Принцип

Не «пять разделов», а один кабинет, где разделы связаны: перенос пары сразу виден в расписании
и в уведомлениях, незакрытый зачёт ведёт к нужному действию, заявка показывает понятный статус.

## Обязательное ядро

| Раздел | Что видит студент |
|---|---|
| Вход и профиль | ФИО, факультет, направление, курс, группа |
| Главная («Сегодня») | ближайшие пары, изменения, дедлайны, статусы заявок |
| Расписание | день/неделя, аудитория, преподаватель, переносы выделены |
| Успеваемость | оценки и зачёты, сессия, итоговая картина |
| Заявки и справки | каталог, форма, статус и история |
| Уведомления | объявления деканата, напоминания, изменения |

## Кандидаты в «смелые» идеи (выбираем 1–2)

1. **Деканат по жизненным ситуациям** — «еду на обмен», «стажировка», «академ»:
   маршрут из документов, сроков и заявлений с общим прогрессом. (Рекомендация Codex.)
2. **Объяснимый учебный радар** — вместо среднего балла конкретные действия:
   «не закрыт зачёт → срок → что сделать → подать обращение».
3. **Языковой маршрут** — подгруппы по языкам, последствия переноса. (Нужно подтвердить.)
4. **Проактивный деканат** — изменение расписания/дедлайн предлагает следующий шаг.

## Тестовые аккаунты (план)

Минимум два студента с разными факультетами/курсами/оценками/заявками
и, если будет, сотрудник деканата (меняет статусы заявок).
