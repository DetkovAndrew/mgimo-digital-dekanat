# План: маршрут внутри корпуса

Запрос капитана: «интеллектуальный маршрут внутри корпусов, пунктиром, по шагам».

Статус: реализовано 12.11.2026. После ревью плана (Codex 27): лестницы связаны явным пролётом (`shaft`), а не
пересечением; сглаживание по прямой видимости не подходит к стенам ближе исходного пути (Дуглас — Пекер убран);
этаж показа отдельно от этажа аудитории; «прошлая пара» — последняя очная неотменённая пара этого дня по МСК,
закончившаяся до начала нужной (на схеме — до текущего момента); предел раскрытых клеток A*. После ревью 28: шаги
в порядке прохождения этажей, «вы уже в аудитории», повороты внутри коридора и галереи, форма «Из другой аудитории».

## Что видит студент
- На схеме корпуса у выбранной аудитории — «Как пройти»: от входа или от аудитории предыдущей пары (если она в этот
  день в том же корпусе и закончилась раньше). Можно выбрать и любую другую аудиторию корпуса как начало.
- На схеме — пунктир по коридорам (анимирован, без анимации при `prefers-reduced-motion`), старт, финиш, переходы
  по лестнице с подписью «на 3 эт.». Маршрут через несколько этажей: на каждом этаже свой отрезок, вкладки этажей
  сохраняют маршрут.
- Под схемой — шаги списком (`<ol>`, это и доступная версия маршрута): «Войдите через главный вход», «Поверните
  налево в коридор крыла 1, около 30 м», «Поднимитесь по лестнице на 3 этаж», «Аудитория 3310 — справа». У шага —
  этаж; шаг на другом этаже — ссылка, переключающая схему.
- Входы: страница пары («Как пройти внутри»), карточка следующей пары на «Сегодня», панель аудитории на схеме.
  «Маршрут» до корпуса (Яндекс Карты) остаётся.

## Как считаем (src/lib/campus/route.ts, чистая функция, без БД)
- Сетка 2×2 единицы схемы на этаж: проходимо то, что лежит в коридоре или холле и не внутри помещения (лестницы,
  туалеты в холлах) и не в проёме «второго света».
- Поиск A* по (этаж, клетка); стоимость шага растёт у стен (расстояние до стены через BFS) — путь идёт по середине
  коридора. Переход между этажами — через лестницы, которые на соседних этажах стоят на одном месте (пересечение
  прямоугольников или совпадение значков в торцах коридоров), фиксированная стоимость за этаж.
- Начало и конец — проём двери (`GeoRoom.door`, `Decor.door`) или середина внешней стены вестибюля «Вход».
- Путь упрощается (Дуглас — Пекер), затем режется на шаги по зонам (коридор крыла N, холл у лестницы, вестибюль,
  атриум, галерея) и поворотам; «слева/справа» у финиша — по стороне двери относительно движения. Метры — условные
  (1 единица ≈ 0,15 м), округление до 5 м.

## Данные и доступ
- Геометрия — публичные данные корпуса (как схема). Начало «предыдущая пара» берётся из расписания студента через DAL
  (`getMySchedule` за этот день) — только номер его аудитории; в URL `from=<номер>` — селектор, проверяется по схеме.
- Неизвестные `from`/`room` — маршрут не строится, страница работает как раньше.

## Тесты
- Модульные: из вестибюля достижима каждая аудитория каждого корпуса; путь не выходит из проходов (точки по отрезкам);
  количество переходов по лестнице = разница этажей; шаги начинаются со входа и заканчиваются аудиторией; маршрут
  аудитория → аудитория на другом этаже.
