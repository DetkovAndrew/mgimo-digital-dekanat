# План: физкультура с честной записью (University)

Правила University (демо, по мотивам ИТМО — см. codex/05): 100 баллов за семестр, тренировка = 5 баллов,
минимум 60 за тренировки (12 тренировок), до 40 дополнительных (соревнования, нормативы);
не больше 2 тренировок в неделю.

## Модель
- `SportSection` — секция (волейбол, фитнес, плавание, настольный теннис, йога…), корпус по умолчанию.
- `SportSlot` — конкретная тренировка: секция, начало/конец, корпус, зал, тренер, вместимость.
- `SportPreference` — приоритеты студента на неделю: (studentId, slotId, rank), уникальны пара
  (studentId, slotId) и (studentId, weekStart, rank). Не больше 6 на неделю.
- `SportDraw` — жеребьёвка недели: weekStart (unique), seed, время, статистика. Повторно не запускается.
- `SportBooking` — (studentId, slotId) unique; статус CONFIRMED / WAITLIST / CANCELLED / ATTENDED / MISSED;
  источник LOTTERY / WAITLIST / FREE_SEAT; позиция в очереди; объяснение («1-й выбор», «2-й выбор — первый заполнен»).
- `SportExtraPoints` — дополнительные баллы (соревнования, нормативы).

## Алгоритм (чистая функция `src/lib/sport/allocate.ts`, тесты)
1. Вход: слоты недели (вместимость), предпочтения студентов, функция доступности слота для студента
   (пересечение с парами, переход до/после с запасом 10 мин на переодевание), квота 2/нед.
2. Случайный порядок студентов из seed (детерминированный PRNG) — время подачи не влияет.
3. Проход 1: каждому — самый предпочтительный доступный слот с местами (максимум 1).
4. Проход 2: второе занятие тем же порядком (не пересекается с уже выданным).
5. Лист ожидания: неудовлетворённые предпочтения студентов, не добравших квоту, в порядке жеребьёвки.
6. Освобождение места (отмена) → первый подходящий из листа ожидания получает место + уведомление.
7. После жеребьёвки оставшиеся места — «свободная запись» (атомарно, с блокировкой слота).

## Экран /sport
Прогресс (баллы, тренировки X из 12, темп «нужно ≈N в неделю»), ближайшие тренировки (отмена),
запись на следующую неделю (приоритеты ↑↓, причины недоступности словами), результат жеребьёвки с
объяснением и местом в очереди, «как это работает». Тренировки попадают в «Сегодня» и расписание
(с переходами). Нижнее меню: Сегодня · Расписание · Учёба · Спорт · Заявки; уведомления — колокольчик.

## Демо
Чтобы жюри прошло сценарий целиком, жеребьёвку следующей недели можно запустить кнопкой
«Демо: провести жеребьёвку сейчас» (один раз на неделю; сбрасывается seed). Для конкуренции seed
создаёт ~40 вымышленных студентов без учётных записей с предпочтениями.

## Безопасность
Все выборки — по studentId из сессии; предпочтения/бронь чужого студента → 404; квоты и вместимость
проверяются на сервере в транзакции; жеребьёвка недели защищена уникальностью SportDraw.weekStart.
