# Кабинет сотрудника деканата

`/staff` — очереди заявок только своего факультета; `/staff/requests/[id]` — поля заявления,
ФИО, группа и курс, история и обработка. Дисклеймер и выход — в собственном layout.
Все страницы, действия и функции DAL вызывают `requireStaff()`. Личные страницы динамические.
Данные других факультетов не выдаются: id заявки всегда проверяется вместе с факультетом.

Смена статуса: Server Action, проверка zod, комментарий до 500 символов (обязателен для
уточнения и отказа), `SELECT … FOR UPDATE OF request` с границей факультета, повторная
проверка ожидаемого статуса, условный UPDATE. Статус, событие STAFF с actorUserId и
уведомление REQUEST_STATUS одному владельцу сохраняются одной транзакцией. Иные поля
из запроса отбрасываются. CSRF/Origin проверяет Next.js для Server Actions.

Переходы: SUBMITTED → IN_PROGRESS/REJECTED; IN_PROGRESS → NEEDS_INFO/READY/REJECTED;
NEEDS_INFO → IN_PROGRESS только после ответа, либо REJECTED; READY → DONE.
Совместимость с существующим студенческим DAL: ответ переводит NEEDS_INFO в SUBMITTED.
Поэтому в ожидании ответа кнопка возобновления скрыта; после ответа заявка появляется
в «Новых» и берётся в работу обычным способом. Общие студенческие файлы не изменены.

При конкуренции карточек с одинаковым ожидаемым статусом проходит один переход.
«Все» сортируется по очередям: новые, в работе, ждут студента, готовы, завершённые;
внутри очереди сначала самые старые. Фильтры — ссылки, действия — радиокнопки,
цели касания от 44 px, текст и поля переносятся при ширине 360 px.
Загрузка карточки показывается индикатором RowLink, запись — состоянием кнопки.
Loading boundary не добавлен, чтобы чужая карточка не превращалась в потоковый soft-404.

Проверки: unit — матрица переходов и границы комментария; integration — факультет,
404 чужого объекта, отказ guard, полный цикл с ответом студента, событие и уведомление
только владельцу, недопустимые переходы, конкурентные изменения. Интеграционные тесты
запускает Claude в среде с доступом к TEST_DATABASE_URL; из песочницы Codex не запускались.

Проверено Codex: TypeScript (`npx tsc --noEmit --incremental false`, после `next typegen`),
общий `npm run lint` и `npm test` (94 теста). Проверку в браузере на 360 px нужно
выполнить отдельно.
