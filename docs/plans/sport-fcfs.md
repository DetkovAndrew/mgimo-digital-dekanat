# Физкультура: «успел — записался» (заменяет жеребьёвку из sport.md)

Капитан 11.11: «жеребьёвка ставит в подвешенное состояние „ехать — не ехать“. Убрать, интерфейс проще».
Правила — по ревью Codex 09 ([codex/09](../ai-log/codex/09-simplify-ai-agent.md), раздел 1).

## Правила (демо University)
1. Запись открывается за 7×24 ч до начала и идёт до начала тренировки. Время и календарь — по Москве.
2. Есть место, нет конфликта, соблюдены «2 в неделю / 1 в день» → сразу «Вы записаны»,
   и тренировка появляется в расписании.
3. Мест нет → «Встать в очередь». Ожидание — не запись: «Место пока не подтверждено».
   В очереди можно стоять максимум на 2 тренировки в неделю.
4. Освободилось место → его получает первый подходящий из очереди (FIFO по времени вступления),
   с повторной проверкой пар, переходов и квот. Прямая запись не обгоняет подходящую очередь:
   перед записью очередь недели продвигается.
5. За 12 ч до начала очередь замирает: новые не встают, продвижения нет.
   Неопределённости «ехать или нет» накануне вечером не остаётся.
6. Все изменения недели — под блокировкой строки `sport_week` (`SELECT … FOR UPDATE`).
   Повторный клик ничего не дублирует: `@@unique(studentId, slotId)`.

## Схема
- Удаляем `SportPreference`, `SportWeekStatus` и поля недели `status`, `deadline`, `seed`, `lotteryOrder`, `drawnAt`.
  `SportWeek` остаётся только как строка для блокировки.
- В `SportBooking` удаляем `rank`, `lotteryIndex`, `explanation`.
  Добавляем `statusAt` — момент последней смены статуса, по нему строится FIFO:
  повторное вступление после выхода ставит в конец.

## Интерфейс
- Сверху компактно: баллы «45/60 за тренировки · 50/100 всего»; подробности и правила свёрнуты.
- «Мои записи»: подтверждённые и очередь (позиция, «место пока не подтверждено»).
- Полоса дней на 7 дней вперёд (`?day=`), под ней тренировки дня. На каждой одна кнопка:
  «Записаться», «В очередь», «Вы записаны» или причина, почему нельзя.

## Seed
Без приоритетов. Симулированные участники заранее занимают места: популярные слоты на ближайших днях
заполнены полностью, у части есть очередь. Тимур стоит в очереди на волейбол.
