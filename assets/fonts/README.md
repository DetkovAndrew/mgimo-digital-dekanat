# Шрифты артефактов

Liberation Sans Regular и Bold используются для PDF-отчёта и подписей листа брендовых
иконок. Шрифт поддерживает кириллицу, разрешает встраивание и поставляется локально,
чтобы воспроизведение не зависело от шрифтов Windows или внешнего CDN.
На геометрию самого SVG-знака шрифт не влияет. В приложение отдельная зависимость не добавлена.

Неизменённые TTF взяты из bundled runtime Codex, пакет `pdfjs-dist/standard_fonts`.
Уведомления Google/Red Hat и полная SIL Open Font License 1.1 сохранены в `LICENSE_LIBERATION`.
