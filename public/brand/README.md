# University: собственный знак

Синий `#3b4cca`, белая U с отделённым верхним модулем: университет как место,
где разрозненные учебные действия собираются вместе. С 19.11 модуль — четырёхлучевая звезда
Инвиктии (помощницы кабинета) вместо квадратной точки. Нейтральная геометрия без герба,
официальных символов, шрифтов и заимствованных иконок. Строгая проверка всех товарных
знаков не проводилась; знак не построен на логотипе какого-либо вуза.

- `mark.svg` — исходный вектор, без внешних ресурсов, встроенного текста и скриптов.
- `icon-32.png`, `icon-192.png`, `icon-512.png` — растровые варианты.
- `apple-touch-icon.png` — 180 px, с непрозрачной подложкой.
- `favicon.ico` — 16/32/48 px; копия используется в `src/app/favicon.ico`.
- `preview.png` — лист для визуальной проверки, в интерфейсе не используется.

Метаданные подключают PNG/SVG и manifest с иконками 192/512. Manifest не делает
кабинет офлайн-приложением; персональные страницы не кешируются service worker.
Изображения обычные (`purpose: any`), не заявлены как maskable.
При объединении с тёмной темой 50d2627 встроенный `UniversityMark` переведён
на существующие токены `brand-fill`/`on-brand`, без тени. Статические брендовые
файлы сохраняют исходный синий; новых цветовых токенов не добавлено.

## Участие ИИ и воспроизведение

Постановка пользователя: «Задачи для NursuUwU — наши задачи, можешь сделать что сможешь».
Дизайн-бриф из TEAM.md: простой собственный SVG, фирменный синий, знак + 32/192/512 px.
Codex написал SVG и подключение; отдельная нейросеть генерации изображений не использовалась.
Геометрия растрируется скриптом `scripts/brand-assets.py` (Pillow), без новых зависимостей приложения.

Первая идея — обычная буква U в квадрате — отброшена до экспорта как слишком общая.
Выбран вариант с отделённым модулем, проверяемый на 16/32 px. Отдельных сгенерированных
«неудачных картинок» нет; не выдаём их за существовавшие артефакты. Принятие визуального
варианта человеком пока не зафиксировано. Разрешение на использование — `LICENSE.txt`.
